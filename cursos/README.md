# Cursos — tracker por curso

**Un archivo por curso.** El tracker es un índice y un resumen, **no otro diario**: estado por
módulo, qué aprendí, qué puedo hacer ahora, hasta 3 fuentes principales + 3 secundarias, y si el
curso dejó entregable. El detalle del día vive en `diario/`; las preguntas de repaso, en `repaso/`.

Plantilla: [`plantillas/tracker-curso.md`](../plantillas/tracker-curso.md) ·
Regla: **el tracker de un curso se abre cuando el curso empieza** (no se pre-crean archivos vacíos).
