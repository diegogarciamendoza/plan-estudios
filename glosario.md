# Glosario SOC — Parte 1 (Semana 1)

> 20 términos base del asistente. **Tarea tuya**: reemplaza "definición base" con TU definición de 1 línea en inglés (tus palabras, no copiada).

| # | Término | Definición base (inglés) |
|---|---|---|
| 1 | threat | A potential cause of an unwanted incident. |
| 2 | vulnerability | A weakness that can be exploited by a threat. |
| 3 | incident | An event that violates security policy or harms assets. |
| 4 | alert | A notification triggered by a detection rule. |
| 5 | triage | Prioritizing alerts by severity and impact. |
| 6 | log | A record of events from a system or application. |
| 7 | SIEM | Security Information and Event Management: centralizes and analyzes logs. |
| 8 | false positive | An alert that is not actually malicious. |
| 9 | IOC | Indicator of Compromise: evidence of an intrusion. |
| 10 | phishing | Social engineering via fake messages to steal credentials. |
| 11 | malware | Malicious software (virus, worm, ransomware...). |
| 12 | exploit | Code or technique that takes advantage of a vulnerability. |
| 13 | authentication | Verifying who a user is (identity). |
| 14 | authorization | Verifying what a user is allowed to do. |
| 15 | firewall | Device/filter that controls traffic by rules. |
| 16 | IDS/IPS | Intrusion Detection/Prevention System: watches/stops attacks. |
| 17 | endpoint | A device connected to the network (PC, server, phone). |
| 18 | malware analyst | Specialist who examines malicious samples. |
| 19 | incident response | Process of detecting, containing, and recovering from incidents. |
| 20 | playbook | Documented procedure for handling a type of incident. |
